Projeto

Empresarial/Consultoria/ProjetoTodas as soluções ↗

Com uma equipa multidisciplinar, a MacWatts está na gênese da solução com o desenvolvimento do projeto de execução, atuando nas seguintes áreas:

 

  • Projeto de Instalações elétrica de Alta, Média e Baixa Tensão;
  • Projeto de Energias Renováveis;
  • Projeto de Gestão Técnica Centralizada
  • Projeto de Instalações de Telecomunicações e Informática;
  • Projeto de Instalações de Segurança Integrada;
  • Projeto de Segurança Contra Incêndios.

 

Com uma visão global, a MacWatts consegue projetar toda a infraestrutura de um edifício, garantindo segurança na exploração, inteligência e sustentabilidade.
